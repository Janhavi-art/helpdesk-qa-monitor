# Wi-Fi Connectivity Troubleshooting

Status: Generic starter guidance. Confirm network-specific steps with your IT team before production use.

## Symptoms
A computer cannot connect to Wi-Fi, frequently disconnects, or cannot reach internal resources.

## Safe checks
1. Confirm Wi-Fi is enabled and Airplane Mode is off.
2. Check whether the computer is within range of the access point.
3. Determine whether other devices can connect to the same network.

## Reconnect
1. Select the approved Wi-Fi network from the device's network settings.
2. If the network profile appears corrupted, follow your organization's instructions for forgetting and rejoining the network.
3. Enter the network credentials only into the operating system's trusted network prompt. Never send passwords in a ticket.

## Restart and escalate
1. If the issue persists, restart the computer and try again.
2. Contact IT if several devices are affected, the network requires a certificate or managed configuration, or the issue persists. Include the device type, approximate time, location/site, and any error message. Do not include passwords or MFA codes.
