# Software Installation

## When to Use This Guide

Use this guide when you need approved software installed on a company computer.

## Check Software Approval

Only install software that is approved by the organization's IT department.

## Installation Steps

1. Open the company software portal.
2. Sign in using your company account.
3. Search for the required software.
4. Check that the software is approved.
5. Select "Install".
6. Wait for the installation to complete.
7. Open the software and verify that it works.

## Administrator Access

Do not bypass administrator restrictions or install unauthorized software.

If administrator permission is required, submit a software installation request to the IT Helpdesk.

## If Installation Fails

Contact the IT Helpdesk if the software does not appear in the software portal, the installation fails, or the application does not start after installation.
