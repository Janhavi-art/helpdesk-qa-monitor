# Wi-Fi Will Not Connect

## Symptoms / task

Check that Wi-Fi is enabled and airplane mode is off. Select the correct network and enter its password carefully. Confirm that the router or access point is powered on. If possible, check whether another device can connect to the same network.

## Recommended steps

If only one device fails, restart that device and forget/rejoin the network if your organization permits it. If multiple devices fail, the network itself may be unavailable. Contact IT support and provide the network name and any error message.
