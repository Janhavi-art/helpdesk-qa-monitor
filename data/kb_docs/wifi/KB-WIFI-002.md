# Wi-Fi Keeps Disconnecting

## Symptoms / task

Move closer to the access point and see whether the signal improves. Restart the computer and check whether the disconnections continue. Note whether the issue happens in one location or everywhere.

## Recommended steps

If multiple devices disconnect, the access point or service may be responsible. Restart network equipment only when you are authorized to do so. Otherwise, contact IT support with the time and location of the drops.
