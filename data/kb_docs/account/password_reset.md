# Password Reset

## When to Reset Your Password

Reset your password if you have forgotten it or if you suspect that
your password has been compromised.

## Steps

1. Open the company password portal.
2. Select "Forgot Password".
3. Enter your company username.
4. Verify your identity using the registered MFA method.
5. Create a new password.
6. Confirm the new password.
7. Sign in again using the new password.

## Password Requirements

The password must contain at least 12 characters.
It should contain uppercase letters, lowercase letters, numbers,
and special characters.

## If Password Reset Fails

Contact the IT Helpdesk if the password portal does not accept
your verification or if your account remains locked.
