# Multi-Factor Authentication Sign-in Issues

Status: Generic starter guidance. Follow official identity-provider guidance for your organization.

## Safe checks
1. Confirm the phone or security key is available and the device has a working network connection.
2. Check the device time if codes are time-based.
3. Use only the authentication prompt you initiated and expected.
4. If recovery is offered, use the official account-recovery route from your company.

## Security
Never approve a sign-in you did not initiate, and never send an MFA code or recovery code to anyone. If you receive unexpected prompts, deny them and report the event to IT/security.

## Escalate
Contact IT if your registered device is lost, you cannot access the recovery method, or sign-in prompts continue unexpectedly. Use the approved identity-verification process.
