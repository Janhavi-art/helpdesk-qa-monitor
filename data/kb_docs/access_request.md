# Requesting Access to an Application

Status: Generic starter guidance. Follow your organization's actual access-request policy.

## Before submitting
Identify the application or resource, the business reason, and the minimum access level needed. Confirm whether the application owner or manager must approve the request.

## Steps
1. Open the official company service portal using a known company link.
2. Select the access-request workflow if available.
3. Enter the application/resource name and explain the business need.
4. Request only the permissions required for the role.
5. Submit the request and follow the normal approval process.

## Escalate
If you cannot find the workflow, ask IT or the application owner for the approved process. Do not request another person's credentials or attempt to bypass access controls. Include the application name and any request/ticket reference when following up.
