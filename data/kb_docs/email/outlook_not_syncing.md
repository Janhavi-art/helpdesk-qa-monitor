# Outlook Email Not Syncing

## When to Use This Guide

Use this guide when Outlook is not receiving new emails or when sent emails are not appearing correctly.

## Check Internet Connection

1. Make sure the computer is connected to the internet.
2. Open a web browser and visit a website.
3. If the internet is not working, resolve the network problem first.

## Restart Outlook

1. Save any open work.
2. Close Outlook completely.
3. Wait a few seconds.
4. Open Outlook again.
5. Check whether new emails appear.

## Check Outlook Connection

Check the status shown at the bottom of Outlook. Make sure Outlook is not displaying "Disconnected" or "Working Offline".

## Restart the Computer

If Outlook still does not synchronize, restart the computer and open Outlook again.

## If the Problem Continues

Contact the IT Helpdesk if Outlook remains disconnected or emails still do not synchronize after restarting the application and computer.
