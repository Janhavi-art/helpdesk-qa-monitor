# Outlook Email Is Not Syncing

Status: Generic starter guidance. Menu names may vary by Outlook version and organization.

## Safe checks
1. Check whether the device has an internet connection.
2. Check whether Outlook is offline or paused, and reconnect if that option is available.
3. Restart Outlook and check whether messages appear in Outlook on the web, if your organization provides it.
4. Confirm that the mailbox is not full if your organization exposes mailbox storage information.

## Escalate
If only one device is affected, note the Outlook version and device. If multiple users are affected or webmail also fails, report a possible service issue to IT. Include the time the problem began and any error code. Do not share passwords or message contents containing sensitive information.
