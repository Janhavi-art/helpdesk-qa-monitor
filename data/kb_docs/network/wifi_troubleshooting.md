# Wi-Fi Troubleshooting

## When to Use This Guide

Use this guide when a laptop or desktop cannot connect to the company Wi-Fi or when the Wi-Fi connection keeps disconnecting.

## Basic Checks

1. Make sure Wi-Fi is turned on.
2. Check that Airplane Mode is turned off.
3. Make sure you are within range of the Wi-Fi router.
4. Check whether other devices can connect to the same Wi-Fi network.

## Reconnect to Wi-Fi

1. Open the Wi-Fi settings.
2. Select the company Wi-Fi network.
3. Choose "Forget".
4. Select the network again.
5. Enter your company Wi-Fi password.
6. Try connecting again.

## Restart the Device

If the problem continues, restart the computer and try connecting to Wi-Fi again.

## If the Problem Continues

Contact the IT Helpdesk if other devices can connect but your computer cannot, or if the connection continues to disconnect after restarting the device.
