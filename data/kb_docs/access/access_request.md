# Access Request

## When to Use This Guide

Use this guide when you need access to a company application, system, shared folder, or other internal resource.

## Before Submitting a Request

Confirm that you have a valid business reason for requesting access and identify the specific resource you need.

## Submit an Access Request

1. Open the company IT service portal.
2. Sign in using your company account.
3. Select "Access Request".
4. Enter the name of the application or resource.
5. Provide the reason for requesting access.
6. Select the required access level.
7. Submit the request.

## Approval

Some access requests require approval from your manager or the resource owner.

Wait for the required approval before attempting to access the resource.

## If Access Is Still Not Available

Contact the IT Helpdesk if your request has been approved but you still cannot access the resource.
