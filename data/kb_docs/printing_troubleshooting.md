# Printer Troubleshooting

Status: Generic starter guidance. Shared printer names and installation instructions are organization-specific.

## Safe checks
1. Confirm the printer is powered on and shows no visible paper or toner warning.
2. Check that the computer and printer are connected to the expected network or approved connection.
3. Confirm the correct printer is selected and the print queue is not paused.
4. If allowed, cancel a stuck job and retry with a small test page.

## Escalate
Contact IT if the printer remains unavailable, multiple users are affected, or a driver/admin permission is required. Include the printer name/location and displayed error. Do not install unapproved drivers or change shared printer settings without authorization.
