# Installing Software on a Work Device

Status: Generic starter guidance. Your organization's application catalog and approval rules take precedence.

## Steps
1. Confirm the software is approved for business use and compatible with the device.
2. Use the company's managed software center or official installation instructions.
3. If administrator permission or approval is requested, submit the approved request instead of bypassing the control.
4. Follow the vendor or company installation instructions and restart only if required.

## Escalate
Contact IT if the software is missing from the catalog, installation fails, a license is unavailable, or administrator access is required. Include the software name, version, device/operating system, and error message. Do not download cracked software or disable security tools to force installation.
