# Shared Drive or File Storage Access

Status: Generic starter guidance. Share names, paths, and access rules are organization-specific.

## Safe checks
1. Confirm that the computer is connected to the company network or approved VPN if remote access requires it.
2. Check that the shared drive path or link was copied correctly.
3. Confirm that you are signed in using the correct company account.
4. If the resource is available to colleagues but not to you, request access through the approved process.

## Escalate
Contact IT if the location cannot be reached, access is denied, or files appear missing. Include the resource path (avoid confidential file contents), your device, whether VPN is connected, and the exact error. Never attempt to bypass file permissions.
